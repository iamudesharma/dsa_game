# Effect PR scope and validation — 29 October 2026

This PR is based on `codex/rust-backend-migration` (PR #3). It adds the Flutter
and React Effect transport policies, provider cancellation/deadlines, corrected
operation hints, template parity data, and reliability tests. Hosted Dart
`effect_core 0.0.3` and npm `effect 4.0.2` are locked.

The unrelated Flutter UI-parity implementation, assets, workflow/agent tooling,
and Rust-guidance changes remain local and are not part of this PR. The shared
Flutter error widget includes only the new error cases; the package manifests
and lockfiles include only the Effect dependency changes.

The October 8–27 validation reports are historical evidence from the combined
working checkout. In particular, native frame measurements, the Explore rebuild
change, and visual/accessibility observations must not be interpreted as validation
of this isolated PR's UI. Their source hashes and dirty-checkout metadata remain
unchanged for traceability. The learning-journey polling adjustment also remains
with that local UI work.

directory and verified independently of the local UI files:
